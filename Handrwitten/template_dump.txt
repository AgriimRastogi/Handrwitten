P017 [Heading 1]: How To Use This Template
P018 [normal]: Read this page once. It is not part of your submission — delete it before you submit.
P019 [Heading 2]: The five rules
P020 [normal]: 1. Delete every grey box. Grey boxes are instructions. Each starts with the marker [REMOVE]. Before submitting, search the document for "[REMOVE]" — if it finds anything, you are not done.
P021 [normal]: 2. One requirement per numbered line. If a line uses "and" to join two different behaviours, split it into two lines.
P022 [normal]: 3. Every requirement uses "shall". "Shall" is a commitment you will be asked to demonstrate live.
P023 [normal]: 4. Requirements must be falsifiable. Someone else must be able to run your application and decide, without asking you, whether the requirement is met. Fast, user-friendly, efficient, robust, accurate, scalable and seamless are not falsifiable — replace each with a number or delete it.
P024 [normal]: 5. Do not copy the examples. Every example here is from an imaginary project called ShelfLife, which predicts how many units of each item a small grocery shop should reorder next week from its past sales records. It is deliberately not one of your projects.
P025 [Heading 2]: You are not expected to know everything yet
P026 [normal]: You have not built this system yet, so you cannot know exactly what it will look like. That is normal and the document is designed around it.
P027 [normal]: So do not agonise over whether each requirement is exactly right. Write the full list of what you think the system should do in Section 5, without worrying about whether every line survives.
P028 [normal]: Then, in Section 7, choose the five you will build first and sort the rest across the project stages. That choice is the part that matters. It is a decision, not a prediction, and you can make it today with what you know now. It is also what you will be asked about first at your next review.
P029 [Heading 2]: Length
P030 [normal]: Five to six pages, excluding the cover page and this page. If you are well over, you have padded it. A longer document is not a better document.
P031 [Heading 2]: If you use an AI assistant
